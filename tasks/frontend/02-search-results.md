# 用户前台 — 搜索结果与配件详情（M2）

**里程碑**：M2  
**依赖**：`frontend/01-home-search`, `api/01-parts-search`, `api/07-ai-matching`  
**预估**：6–7 人天

## 任务列表

### T1: 搜索结果页 `[x]`

展示内容（PRD §8.7）：

- [x] 用户原始输入
- [x] 系统识别出的关键信息（`extracted_info`）
- [x] 匹配状态标签：精确 / 高可能 / 多候选 / 信息不足 / 未找到
- [x] 推荐配件列表卡片：
  - 图片、名称、Part Number、OEM、替代编号
  - 适配设备、适配发动机、规格、库存、参考价格
  - 置信度进度条/百分比
  - 匹配原因（可展开查看 evidence）
  - 风险提示（低置信度、安全类配件）
- [x] 「加入采购清单」按钮
- [x] 「人工确认」按钮

**验收**：搜索后完整展示匹配结果与置信度。

---

### T2: 多候选选择 `[x]`

- `match_status: multiple` 时展示候选对比
- 用户选择确认后高亮选中项
- 选中后可加入清单

**验收**：多候选场景用户可选择后操作。

---

### T3: 信息不足 / 未找到引导 `[x]`

- `insufficient`：展示补充建议（品牌、型号、铭牌、照片）
- `not_found`：引导提交人工查询，预填已有信息
- 内嵌快捷补充表单或跳转 `/inquiry`

**验收**（PRD §8.7）：无结果时有明确下一步引导。

---

### T4: 配件详情页 `[x]`

路由：`/parts/:id`

字段（PRD §8.8）：
- 配件图片轮播
- 名称、Part Number、SKU、OEM、替代编号、品牌、分类
- 适配设备列表、适配发动机、序列号范围
- 规格参数表、包装信息、单位、参考价格、库存
- 替代件列表（可跳转详情）
- 注意事项
- 「加入采购清单」「咨询人工」按钮

**验收**：详情页字段完整，加载 ≤ 2s 感知。

---

### T5: 替代件展示 `[x]`

- 详情页内替代件 Tab 或折叠区
- 标注关系类型与可靠度
- 可跳转替代件详情

**验收**：OEM 查询场景可查看替代件。

---

### T6: 加入清单联动 `[x]`

- 调用 `POST /api/v1/cart/items/from-match`
- 成功 toast + 更新清单角标
- 低置信度添加前弹窗确认

**验收**：从结果页/详情页可加入清单并看到角标变化。
