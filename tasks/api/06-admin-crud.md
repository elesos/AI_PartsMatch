# API 服务 — 后台数据管理（M1）

**里程碑**：M1  
**依赖**：`api/00-foundation`  
**预估**：8–10 人天

## 任务列表

### T1: 配件管理 CRUD `[x]`

**接口**：`/api/v1/admin/parts`

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/parts` | 列表（分页、搜索、分类筛选） |
| POST | `/parts` | 新增 |
| GET | `/parts/{id}` | 详情 |
| PUT | `/parts/{id}` | 更新 |
| DELETE | `/parts/{id}` | 软删除/下架 |
| POST | `/parts/{id}/images` | 上传配件图片 |

字段（PRD §11.1）：SKU, Part Number, OEM, 中/英/越名称, 品牌, 分类, 规格, 价格, 库存, 上下架状态。

**验收**（PRD §16.4-1）：管理员可新增、编辑、下架配件。

---

### T2: 设备管理 CRUD `[x]`

**接口**：`/api/v1/admin/machines`

- 字段：设备类型、品牌、型号、系列、年份、地区、发动机型号
- 支持按品牌/类型筛选

**验收**（PRD §16.4-2）：可维护整机型号数据。

---

### T3: 整机-配件适配关系 `[x]`

**接口**：`/api/v1/admin/relations/machine-part`

- 字段：设备 ID、配件 ID、配件系统、位置、序列号起止、适配说明、优先级
- 批量导入接口（CSV）

**验收**（PRD §16.4-3）：可维护设备与配件适配关系。

---

### T4: 替代件关系管理 `[x]`

**接口**：`/api/v1/admin/cross-refs`

- 字段：原编号、替代编号、关系类型、可靠度、适配限制
- 支持按 Part Number 双向查询

**验收**（PRD §16.4-4）：可维护替代件关系。

---

### T5: 配件别名管理 `[x]`

**接口**：`/api/v1/admin/aliases`

- 字段：配件 ID、别名、语言、地区、来源、状态
- 支持待审核 → 有效流转

**验收**：多语言别名可维护，供搜索使用。

---

### T6: 配件分类管理 `[x]`

**接口**：`/api/v1/admin/categories`

- 一级分类（PRD §9.1）
- 叉车/挖机重点子分类（PRD §9.2, §9.3）可作为二级

**验收**：分类数据可维护，供前台导航使用。

---

### T7: 种子数据脚本 `[x]`

- 导入样例：Toyota 叉车、CAT 挖机、Heli 叉车等高频品牌
- 每品牌 ≥ 10 个配件、≥ 3 个替代件关系
- CLI：`python scripts/seed.py` 或 `npm run seed`

**验收**：空库执行种子脚本后可进行搜索演示。

---

### T8: 数据校验规则 `[x]`

- Part Number 同品牌不可重复
- 价格 ≥ 0
- 上下架配件不可加入清单（搜索时过滤）
- 关系表引用完整性检查

**验收**：非法数据提交返回 422 与明确字段错误。
