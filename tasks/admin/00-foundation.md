# 管理后台 — 基础设施（M0）

**里程碑**：M0  
**依赖**：`api/00-foundation`  
**预估**：3–4 人天

## 任务列表

### T1: 项目初始化 `[x]`

- 创建后台项目（推荐 Ant Design Pro / shadcn-admin / 与前台同框架）
- 目录：`pages/`, `components/`, `services/`, `layouts/`
- 环境变量：`VITE_API_BASE_URL`

**验收**：后台可独立启动。

---

### T2: 登录与权限 `[x]`

- 登录页：用户名 + 密码
- 调用 `POST /api/v1/admin/auth/login`
- Token 存储与自动刷新
- 路由守卫：未登录跳转登录页
- 角色区分：`admin` 全权限，`operator` 工单+查看

**验收**：登录后可进入后台，未登录被拦截。

---

### T3: 后台布局 `[x]`

- 侧边栏菜单：
  - 配件管理
  - 设备管理
  - 替代件管理
  - 适配关系（V1.0 可合并到设备管理）
  - 工单管理
  - 查询日志
- 顶栏：用户信息、退出登录
- 面包屑导航

**验收**：菜单结构清晰，可导航各模块。

---

### T4: API Client `[x]`

- 复用与前台类似的封装
- 自动附加 `Authorization: Bearer {token}`
- 401 自动跳转登录

**验收**：登录后可调用 admin API。

---

### T5: 通用 CRUD 组件 `[x]`

- 数据表格（分页、搜索、排序）
- 表单弹窗（新增/编辑）
- 确认删除对话框
- 图片上传组件

**验收**：各管理页可复用组件快速搭建。
