# AI_PartsMatch
内容主要参考了手稿中的“配件下单及采购”入口、拍照识别/Excel 批量上传、语言切换、AI 找配件、清单页、不能识别时转人工、按 IP 显示语言顺序、购物车合并生成订单等流程；同时本版暂不考虑支付和物流，重点放在“配件精确匹配 + 后台配件知识库 + AI 大模型检索”。 

配件查询与采购系统 PRD

1. 文档信息

项目	内容
产品名称	配件查询与采购系统
文档版本	V1.0
核心目标	帮助用户快速、准确找到适配的配件，并加入采购清单
当前范围	配件查询、AI 匹配、配件信息管理、购物车/采购清单
暂不包含	在线支付、物流、发货、售后流程

⸻

2. 背景与问题

用户在采购设备配件时，常见问题包括：

1. 不清楚配件的准确名称、型号、编码。
2. 只知道设备铭牌、整机型号、照片或部分描述，无法直接定位配件。
3. 不同地区、不同语言用户表达方式不同，客服人工沟通成本高。
4. 配件信息分散，缺少结构化后台管理和知识库支持。
5. 批量采购时，用户希望通过 Excel 快速上传清单，而不是逐个搜索。

因此，需要建设一个面向用户的配件查询与采购系统，通过 AI 大模型、配件知识库和后台结构化数据，帮助用户精准匹配所需配件。

⸻

3. 产品目标

3.1 用户目标

用户可以通过以下方式快速找到配件：

1. 输入配件名称、型号、编码、设备型号等关键词搜索。
2. 上传配件照片或整机铭牌照片，由系统识别并推荐配件。
3. 上传 Excel 批量配件清单，系统自动解析并匹配配件。
4. 在无法精确识别时，补充更多信息或转人工协助。
5. 将确认后的配件加入采购清单或购物车。

3.2 平台目标

平台需要实现：

1. 建立统一的配件信息库。
2. 建立配件与设备、型号、铭牌、图片、关键词之间的关联关系。
3. 接入 AI 大模型与知识库，提高模糊查询和图片识别能力。
4. 支持多语言用户查询。
5. 降低人工客服介入比例，提高查询效率和匹配准确率。

6. 核心业务流程

6.1 单个配件查询流程

1. 用户进入配件查询页面。
2. 用户选择查询方式：
    * 文本输入；
    * 上传配件照片；
    * 上传整机铭牌照片；
    * 填写整机型号、配件型号或其他描述。
3. 系统调用 AI 识别和知识库检索。
4. 系统返回匹配结果：
    * 精确匹配；
    * 可能匹配；
    * 未匹配。
5. 用户查看配件信息。
6. 用户选择数量。
7. 用户加入购物车/采购清单。
8. 如果无法确认，用户可选择“人工帮我查”。

⸻

6.2 批量配件查询流程

1. 用户进入批量上传入口。
2. 用户下载 Excel 模板。
3. 用户按照模板填写配件信息。
4. 用户上传 Excel 文件。
5. 系统解析 Excel 内容。
6. 系统逐行匹配配件。
7. 系统展示批量匹配结果：
    * 已找到；
    * 多个候选；
    * 未找到；
    * 需要补充信息。
8. 用户确认或修改匹配结果。
9. 用户批量加入采购清单。
10. 未找到的内容可提交人工查询。

⸻

6.3 图片识别流程

1. 用户上传配件照片或整机铭牌照片。
2. 系统识别图片内容：
    * 配件外观；
    * 型号；
    * 编码；
    * 品牌；
    * 设备铭牌信息；
    * 文字信息。
3. 系统提取结构化信息。
4. 系统调用知识库进行匹配。
5. 返回推荐配件。
6. 用户确认结果。
7. 用户加入采购清单或提交人工查询。

⸻

6.4 未匹配转人工流程

1. 系统提示“暂未找到准确配件”。
2. 用户可选择：
    * 上传更多照片；
    * 填写补充信息；
    * 提交人工查询。
3. 用户补充以下信息：
    * 姓名；
    * 联系方式；
    * 国家/地区；
    * 设备型号；
    * 配件描述；
    * 图片附件；
    * 期望数量。
4. 系统生成工单。
5. 客服人员在后台处理。
6. 客服确认配件后，将结果回填给用户。
7. 用户可将人工确认的配件加入采购清单。

7.1.2 文本搜索配件

功能说明

3. 整机型号。
4. 配件编码。
5. 品牌。

2. 配件编码。

4. 配件图片。

6. 参考价格。

7.1.3 图片上传识别

功能说明

用户上传配件照片或整机铭牌照片，系统识别图片并匹配配件。

支持图片类型

1. JPG。
2. PNG。
3. HEIC。
4. WebP。

支持上传内容

1. 配件实物照片。
2. 整机铭牌照片。
3. 包装标签照片。
4. 零件编号照片。
5. 多张辅助照片。

识别内容

1. 图片中的文字。
2. 型号。
3. 编码。
4. 品牌。
5. 外观特征。
6. 设备序列号。
7. 铭牌参数。

结果展示

1. 精确匹配结果。
2. 可能匹配结果。
3. 需要补充的信息。
4. 无法识别提示。
5. 转人工查询入口。

异常处理

1. 图片模糊：提示用户重新上传清晰图片。
2. 信息不足：提示用户补充整机铭牌或配件编号。
3. 多个候选：展示候选列表，由用户选择。
4. 未找到：引导用户提交人工查询。

7.2 AI 匹配功能

7.2.1 AI 匹配目标

AI 需要帮助用户在信息不完整、不准确、多语言表达、图片模糊等情况下，尽可能找到正确配件。

7.2.2 AI 输入

1. 用户搜索关键词。
2. 用户自然语言描述。
3. 用户上传图片。
4. OCR 识别文字。
5. Excel 批量上传内容。
6. 整机型号。
7. 铭牌信息。
8. 历史匹配数据。
9. 后台配件知识库。

7.2.3 AI 输出

1. 推荐配件列表。
2. 匹配置信度。
3. 匹配原因。
4. 缺失信息提示。
5. 是否建议人工介入。
6. 可追溯的知识库来源。

7.2.4 匹配策略

1. 精确匹配

优先使用以下字段：

1. 配件编码。
2. 配件型号。
3. OEM 编号。
4. SKU。
5. 条码。
6. 整机型号 + 配件编码。

2. 模糊匹配

当用户输入不完整时，使用：

1. 配件别名。
2. 多语言名称。
3. 拼写纠错。
4. 近义词。
5. 语义向量检索。
6. 历史人工匹配记录。

3. 图片匹配

通过图片识别：

1. OCR 提取文字。
2. 图像特征识别。
3. 铭牌信息解析。
4. 包装标签识别。
5. 外观相似度匹配。

4. 知识库增强匹配

AI 需结合知识库回答：

1. 某整机型号适配哪些配件。
2. 某配件可用于哪些设备。
3. 某旧型号是否有替代型号。
4. 某地区是否使用不同型号。
5. 某配件是否存在多个版本。

7.2.5 置信度规则

置信度	状态	处理方式
≥ 90%	精确匹配	可直接推荐
70%-89%	高可能匹配	展示候选并提示用户确认
40%-69%	低置信度	展示候选，建议人工确认
< 40%	未匹配	引导补充信息或转人工

10. 非功能需求

10.1 性能要求

1. 文本搜索响应时间 ≤ 3 秒。
2. 图片识别初步返回时间 ≤ 10 秒。
3. Excel 100 行以内解析时间 ≤ 30 秒。
4. 常规配件详情页加载时间 ≤ 2 秒。

10.2 准确性要求

1. 精确编码查询准确率 ≥ 98%。
2. 型号查询准确率 ≥ 90%。
3. 图片识别推荐准确率首期目标 ≥ 70%。
4. AI 推荐结果必须展示置信度和匹配原因。
5. 低置信度结果必须提示用户确认或转人工。

10.3 安全要求

1. 上传文件需进行格式校验。
2. 上传图片需进行大小限制。
3. Excel 文件需防止恶意脚本。
4. 后台操作需权限控制。
5. 用户联系方式需脱敏展示。
6. AI 调用日志需记录但不能泄露敏感信息。

10.4 可扩展性要求

1. 支持新增语言。
2. 支持新增配件分类。
3. 支持新增 AI 模型。
4. 支持知识库持续更新。
5. 支持后续接入支付、物流和订单履约。

12. 验收标准

12.1 文本查询

1. 输入准确配件编码时，系统能返回唯一配件。
2. 输入整机型号 + 配件名称时，系统能返回相关候选。
3. 输入模糊描述时，系统能给出合理推荐或提示补充信息。

12.2 图片识别

1. 上传清晰铭牌照片后，系统能识别型号或编码。
2. 上传配件照片后，系统能返回候选配件。
3. 图片不清晰时，系统能提示用户重新上传。
4. 无法识别时，系统能引导人工查询。

12.3 Excel 批量上传

1. 用户可下载模板。
2. 用户上传模板后，系统可解析数据。
3. 系统可逐行展示匹配结果。
4. 用户可批量加入采购清单。
5. 未匹配项可转人工处理。

12.4 后台配件管理

1. 管理员可新增、编辑、下架配件。
2. 管理员可维护多语言名称。
3. 管理员可维护配件图片。
4. 管理员可维护整机与配件关系。
5. 管理员可导入知识库内容。

12.5 AI 匹配

1. AI 返回结果需包含置信度。
2. AI 返回结果需包含匹配原因。
3. AI 低置信度时不能直接让用户误认为精确匹配。
4. 人工修正结果可沉淀到知识库。

14. 关键风险与解决方案

风险	说明	解决方案
配件数据不完整	用户无法精准查询	先完善高频配件和整机适配关系
图片识别准确率不足	用户上传图片质量参差不齐	提示上传规范，并提供人工兜底
AI 推荐错误	错误配件可能影响采购	展示置信度，低置信度必须人工确认
多语言表达复杂	不同地区用户描述不同	建立多语言别名和关键词库
批量上传格式不统一	Excel 数据难解析	提供标准模板和字段校验
人工工单堆积	未匹配请求过多	建立知识库回填机制，减少重复人工处理

15. 本期 MVP 建议

1. 配件搜索首页。
2. 文本搜索配件。
3. 图片上传识别。
4. Excel 模板下载与批量上传。
5. 配件匹配结果展示。
6. 加入采购清单。
7. 人工查询表单。
8. 后台配件信息管理。
9. 后台知识库管理。
10. AI 匹配接口与日志记录。

暂不做支付、物流、复杂订单履约，仅完成“找到正确配件并形成采购清单”的闭环。
