# API 服务 — 多语言支持（M8）

**里程碑**：M8  
**依赖**：`api/01-parts-search`  
**预估**：3–4 人天

## 任务列表

### T1: 语言配置接口 `[x]`

**接口**：
- `GET /api/v1/i18n/languages` — 返回支持语言列表 `zh`, `en`, `vi`
- `GET /api/v1/i18n/messages?lang=zh` — 返回系统固定文案（错误提示、引导语）

**验收**：前台可拉取语言列表与文案包。

---

### T2: 配件多语言名称 `[x]`

- 搜索与详情根据 `lang` 参数返回对应 `name_cn` / `name_en` / `name_vi`
- 回退策略：请求语言 → 英文 → 中文

**验收**：切换语言后配件名称对应变化。

---

### T3: 用户语言偏好 `[x]`

**接口**：
- `POST /api/v1/i18n/preference` — 保存用户语言选择
- 存储：Cookie / `session` 记录
- MVP 默认语言规则（PRD §8.11）：
  - 中国 IP → 中文
  - 越南 IP → 越南语
  - 其他 → 英文
- 用户手动选择后优先使用用户选择

**验收**：语言偏好持久化，下次访问生效。

---

### T4: 搜索多语言输入 `[x]`

- 搜索接口接受 `lang` 参数
- 别名表按语言匹配（`part_alias.language`）
- 非中文输入时 AI 翻译后再搜索

**验收**（PRD §8.11）：英/越语搜索可返回结果。

---

### T5: Excel 模板多语言 `[x]`

- 模板下载支持 `?lang=en|vi`
- 表头与说明行对应翻译

**验收**：海外用户可下载英文/越南语模板。
