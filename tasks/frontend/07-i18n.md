# 用户前台 — 多语言（M8）

**里程碑**：M8  
**依赖**：`frontend/00-foundation`, `api/08-i18n`  
**预估**：4–5 人天

## 任务列表

### T1: i18n 框架接入 `[ ]`

- 集成 vue-i18n / react-i18next / next-intl
- 语言文件：`locales/zh.json`, `en.json`, `vi.json`
- 覆盖范围：导航、按钮、表单标签、错误提示、空状态

**验收**：切换语言后界面文案变化。

---

### T2: 语言切换器 `[ ]`

- 顶部导航下拉：中文 / English / Tiếng Việt
- 切换后调用 `POST /api/v1/i18n/preference`
- 刷新或跳转后保持选择

**验收**（PRD §8.11-5,6）：手动切换并持久化。

---

### T3: 默认语言检测 `[ ]`

- 首次访问根据 API 返回的推荐语言（基于 IP）设置默认
- 用户未手动选择前使用推荐语言

**验收**（PRD §8.11-1~4）：默认语言规则生效。

---

### T4: 配件名称多语言 `[ ]`

- 搜索/详情请求带 `lang` 参数
- 展示 API 返回的对应语言名称
- 回退显示英文或中文

**验收**：切换语言后配件名对应变化。

---

### T5: 搜索框多语言 `[ ]`

- 各语言搜索 placeholder
- 支持用户用英/越语输入搜索

**验收**（PRD §8.11 AI 多语言）：多语言搜索可用。

---

### T6: Excel 模板多语言 `[ ]`

- 下载模板时传递当前 `lang`
- 批量页说明文案翻译

**验收**：海外用户可理解模板字段含义。
