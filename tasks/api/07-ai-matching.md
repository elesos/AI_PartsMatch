# API 服务 — AI 候选推荐与日志（M6）

**里程碑**：M6  
**依赖**：`api/01-parts-search`  
**预估**：6–8 人天

## 任务列表

### T1: 自然语言意图理解 `[ ]`

- 接入大模型 API（OpenAI 兼容）
- 输入用户自然语言描述，输出结构化查询条件：
  ```json
  {
    "intent": "find_part",
    "part_category": "滤芯",
    "machine_brand": "Komatsu",
    "machine_model": "PC200",
    "part_no": null,
    "quantity": 1,
    "lang": "zh"
  }
  ```
- 支持中/英/越输入（PRD §8.11）
- 多语言描述自动翻译为标准查询条件

**验收**（PRD §16.1-5）：模糊描述可解析为查询条件或返回候选。

---

### T2: 多路匹配综合排序 `[ ]`

匹配优先级（PRD §10.5）：

| 优先级 | 方式 |
|--------|------|
| P0 | Part Number / OEM 精确 |
| P1 | 替代编号 |
| P2 | 品牌 + 型号 + 序列号 |
| P3 | 发动机 + 分类 |
| P4 | 铭牌 OCR + DB |
| P5 | RAG（V1.1 `[-]`） |
| P6 | 图片相似（V1.2 `[-]`） |
| P7 | 自然语言语义 |
| P8 | 人工确认 |

- 合并多路结果，AI 辅助重排序
- 返回 Top N 候选（默认 10）

**验收**：综合搜索返回合理排序的候选列表。

---

### T3: 置信度计算与状态判定 `[ ]`

规则（PRD §10.6）：

| 置信度 | 状态 | 处理 |
|--------|------|------|
| ≥ 90% | exact | 可推荐加入清单 |
| 70–89% | high | 需用户确认 |
| 40–69% | low | 建议人工 |
| < 40% | not_found | 引导补充/人工 |

限制：
- 发动机/液压/电气/制动件：置信度封顶 89%（不可标 exact）
- 图片相似不能作为唯一依据

**验收**（PRD §16.5-4）：低置信度不标记为精确匹配。

---

### T4: 匹配依据与证据输出 `[ ]`

- 每个候选附带 `reason`（人类可读）和 `evidence[]`：
  ```json
  {
    "type": "part_no|oem|machine|rag|ocr|ai",
    "content": "匹配依据描述",
    "source_ref": "数据来源",
    "confidence": 0.85
  }
  ```
- 写入 `ai_match_evidence` 表

**验收**（PRD §16.5-1,2,3）：推荐含置信度、原因、可追溯证据。

---

### T5: 查询日志 `[ ]`

**接口**：`GET /api/v1/admin/query-logs`

- 每次搜索写入 `part_query_log`
- 字段：用户/会话、查询类型、原始输入、提取信息、AI 结果、置信度、是否转人工
- 支持按日期、类型、匹配状态筛选

**验收**（PRD §17.1-14）：查询有完整日志记录。

---

### T6: 需人工介入判断 `[ ]`

- AI 输出 `need_manual: true` 条件：
  - 置信度 < 40%
  - 多个候选置信度接近（差值 < 5%）
  - 关键安全类配件且置信度 < 90%
- 生成建议补充问题列表

**验收**：低置信度场景正确建议转人工。

---

### T7: AI 调用日志与安全 `[ ]`

- 记录每次 LLM 调用的 prompt hash、token 用量、耗时
- API Key 仅存服务端
- 限流：每 IP 每分钟 ≤ 20 次 AI 搜索

**验收**（PRD §14.3-6,7）：AI 调用可追溯，有基本限流。
