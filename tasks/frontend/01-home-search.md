# 用户前台 — 首页与文本搜索（M2）

**里程碑**：M2  
**依赖**：`frontend/00-foundation`, `api/01-parts-search`  
**预估**：5–6 人天

## 任务列表

### T1: 配件查询首页 `[x]`

页面元素（PRD §8.1）：

- [x] Logo + 系统名称
- [x] 语言切换器
- [x] 主搜索框（占位：Part Number / OEM / 设备型号 / 发动机型号 / 配件名称）
- [x] 上传照片按钮 → `/upload`
- [x] 上传铭牌按钮 → `/upload?type=nameplate`
- [x] Excel 批量上传入口 → `/batch`
- [x] Excel 模板下载（调用 API）
- [x] 采购清单入口（角标显示数量）
- [x] 人工客服入口
- [x] 常见配件分类入口（调用 `/categories`）
- [x] 热门设备型号入口（调用 `/machines/hot`）

**验收**：首页所有入口可点击跳转或触发 API。

---

### T2: 搜索交互 `[x]`

- 搜索框支持回车/按钮提交
- 跳转 `/search?q={query}` 或 POST 后展示结果
- 搜索中 loading 状态
- 空输入校验提示

**验收**：输入 Part Number 可发起搜索并跳转结果页。

---

### T3: 搜索历史（本地）`[x]`

- localStorage 保存最近 10 条搜索
- 首页搜索框下方展示历史，点击可复搜

**验收**：刷新页面后历史仍可见。

---

### T4: 快捷查询方式 `[x]`

首页提供查询方式标签/tab：
- 按编号 / 按设备型号 / 按发动机型号
- 切换后搜索框 placeholder 与 API `type` 参数联动

**验收**：不同查询方式调用对应搜索 API。
