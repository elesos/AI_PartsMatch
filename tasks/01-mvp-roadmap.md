# MVP 路线图

基于 PRD §17 版本规划，将任务按阶段组织，明确各阶段交付物与依赖关系。

## 版本对照

| 版本 | PRD 章节 | 本期任务范围 |
|------|----------|--------------|
| **V1.0 MVP** | §17.1 | ✅ 全部实现 |
| V1.1 | §17.2 | RAG、序列号、发动机关系等 |
| V1.2 | §17.3 | 图片相似度、收藏、导出等 |

## V1.0 MVP 里程碑

### M0：项目脚手架（1 周）

| 交付物 | API | 前台 | 后台 |
|--------|-----|------|------|
| 项目初始化 | `api/00-foundation` | `frontend/00-foundation` | `admin/00-foundation` |
| 开发环境 Docker Compose | DB + Redis + MinIO | — | — |
| API 健康检查 `/health` | ✅ | — | — |
| 前后端联调基线 | CORS、环境变量 | API Client 封装 | 同上 |

**验收**：三端可本地启动，前台能调用 `/health` 并展示结果。

---

### M1：基础数据管理（2 周）

| 交付物 | 任务文档 |
|--------|----------|
| 配件 CRUD API | `api/06-admin-crud` → T1 |
| 设备 CRUD API | `api/06-admin-crud` → T2 |
| 替代件关系 API | `api/06-admin-crud` → T3 |
| 配件别名 API | `api/06-admin-crud` → T4 |
| 后台配件管理页 | `admin/01-parts-management` |
| 后台设备管理页 | `admin/02-machine-management` |
| 后台替代件管理页 | `admin/03-cross-reference` |

**验收**：管理员可录入配件、设备、替代件；前台可通过 API 获取配件详情。

**依赖**：M0

---

### M2：文本搜索与精确匹配（2 周）

| 交付物 | 任务文档 |
|--------|----------|
| Part Number 精确匹配 | `api/01-parts-search` → T1 |
| OEM 编号匹配 + 替代件 | `api/01-parts-search` → T2 |
| 设备型号 → 配件分类 | `api/01-parts-search` → T3 |
| 配件名称/别名模糊搜索 | `api/01-parts-search` → T4 |
| 查询首页 + 搜索框 | `frontend/01-home-search` |
| 搜索结果页 | `frontend/02-search-results` |
| 配件详情页 | `frontend/02-search-results` → T3 |

**验收**（PRD §16.1）：
- 准确 Part Number 返回唯一配件
- OEM 编号返回原厂件 + 替代件
- 整机型号展示相关配件分类
- 模糊描述返回候选或提示补充

**依赖**：M1

---

### M3：采购清单（1 周）

| 交付物 | 任务文档 |
|--------|----------|
| 清单 CRUD API | `api/04-cart` |
| 重复合并、数量修改 | `api/04-cart` → T2 |
| 采购意向单提交 | `api/04-cart` → T3 |
| 采购清单页 | `frontend/05-cart` |
| 各页面「加入清单」按钮打通 | `frontend/02-search-results` 等 |

**验收**（PRD §8.9）：
- 可增删改数量
- 相同配件自动合并
- 低置信度标记「建议人工确认」
- 可提交采购意向（无支付）

**依赖**：M2

---

### M4：图片上传与 OCR（2 周）

| 交付物 | 任务文档 |
|--------|----------|
| 图片上传 API | `api/02-image-ocr` → T1 |
| OCR 文字提取 | `api/02-image-ocr` → T2 |
| 铭牌字段解析（品牌/型号/序列号） | `api/02-image-ocr` → T3 |
| 图片类型判断 | `api/02-image-ocr` → T4 |
| OCR 结果 → 搜索匹配联动 | `api/02-image-ocr` → T5 |
| 图片上传页 | `frontend/03-image-upload` |
| 铭牌识别结果页 | `frontend/03-image-upload` → T2 |

**验收**（PRD §16.2）：
- 清晰铭牌识别设备型号
- 配件编号照片提取 Part Number
- 模糊图片提示重传
- 无法识别引导人工查询

**依赖**：M2

---

### M5：Excel 批量匹配（1.5 周）

| 交付物 | 任务文档 |
|--------|----------|
| Excel 模板生成与下载 | `api/03-excel-batch` → T1 |
| Excel 解析与校验 | `api/03-excel-batch` → T2 |
| 逐行匹配（复用搜索引擎） | `api/03-excel-batch` → T3 |
| 批量加入清单 | `api/03-excel-batch` → T4 |

**验收**（PRD §16.3）：

**依赖**：M2, M3

### M6：AI 候选推荐与日志（1.5 周）

| 交付物 | 任务文档 |
|--------|----------|
| 自然语言意图理解 | `api/07-ai-matching` → T1 |
| 多路匹配结果综合排序 | `api/07-ai-matching` → T2 |
| 置信度与匹配依据输出 | `api/07-ai-matching` → T3 |
| 查询日志记录 | `api/07-ai-matching` → T4 |
| AI 匹配证据记录 | `api/07-ai-matching` → T5 |

### M7：人工查询工单（1.5 周）

| 交付物 | 任务文档 |
|--------|----------|
| 工单创建 API | `api/05-manual-ticket` → T1 |
| 工单状态流转 | `api/05-manual-ticket` → T2 |
| 客服回填配件 | `api/05-manual-ticket` → T3 |
| 人工查询表单页 | `frontend/06-manual-inquiry` |

### M8：多语言（1 周）

| 交付物 | 任务文档 |
|--------|----------|
| 语言检测与切换 API | `api/08-i18n` |
| 配件多语言名称 | 复用 `part.name_cn/en/vi` |
| 前台 i18n 框架 | `frontend/07-i18n` |
| 中/英/越文案 | 前台 + 后台关键界面 |

**验收**（PRD §8.11）：
