# 用户前台 — 人工查询（M7）

**里程碑**：M7  
**依赖**：`frontend/00-foundation`, `api/05-manual-ticket`  
**预估**：4–5 人天

## 任务列表

### T1: 人工查询表单页 `[ ]`

路由：`/inquiry`

表单字段（PRD §8.10）：
- 联系人姓名 *
- 国家/地区 *
- 联系方式 *
- 沟通工具 *（VX / WhatsApp / Zalo / Telegram）
- 设备类型、品牌、整机型号、序列号、发动机型号
- 配件描述 *
- 所需数量 *
- 图片附件（多图上传）
- 备注

- 支持 URL query 预填（从搜索/图片/批量跳转带入上下文）
- 表单校验与提交 loading

**验收**：可填写并提交工单。

---

### T2: 提交成功页 `[ ]`

路由：`/inquiry/success`

- 展示工单号
- 预计处理时间提示
- 客服联系方式（WhatsApp 等外链）
- 「返回首页」「查看清单」按钮

**验收**：提交后有明确反馈。

---

### T3: 全局「转人工」入口 `[ ]`

在以下场景嵌入「人工帮我查」按钮：
- 搜索结果页（未找到/低置信度/多候选）
- 图片识别结果页（无匹配）
- 批量结果页（未匹配行）
- 配件详情页「咨询人工」
- 顶部导航人工客服入口

**验收**（PRD §8.10 入口位置）：6 个入口均可达。

---

### T4: 上下文预填 `[ ]`

跳转 `/inquiry` 时通过 state/query 传递：
- 已有设备信息、配件描述
- 关联 `query_id` / `batch_id` / `image_ids`
- AI 初步推荐结果

**验收**：用户无需重复填写已识别信息。

---

### T5: 工单状态查看（可选 MVP）`[ ]`

- 用户凭工单号查询状态（简单查询页）
- 展示：pending / processing / matched 等

**验收**：用户可查看工单处理进度。
