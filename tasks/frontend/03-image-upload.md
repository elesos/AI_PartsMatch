# 用户前台 — 图片/铭牌上传识别（M4）

**里程碑**：M4  
**依赖**：`frontend/00-foundation`, `api/02-image-ocr`, `frontend/02-search-results`  
**预估**：5–6 人天

## 任务列表

### T1: 图片上传页 `[x]`

路由：`/upload`

- 支持拖拽/点击上传
- 格式提示：JPG, PNG, HEIC, WebP
- 单张 ≤ 10MB，最多 5 张
- 上传类型选择：配件照片 / 整机铭牌 / 发动机铭牌 / 包装标签
- URL 参数 `?type=nameplate` 预选铭牌模式
- 上传进度条

**验收**：可上传图片并看到预览。

---

### T2: 识别进行中状态 `[x]`

- 上传后自动触发 OCR + 匹配
- 分步展示：上传中 → 识别中 → 匹配中
- 超时（>10s）提示耐心等待或稍后查看

**验收**：用户感知处理进度。

---

### T3: 铭牌/图片识别结果页 `[x]`

路由：`/upload/result`

展示（PRD §8.3, §8.4）：
- 原图预览
- 识别出的文字（OCR 原文）
- 结构化字段：品牌、型号、序列号、发动机型号、Part Number、OEM
- 字段可手动编辑修正
- 「重新识别」「确认并搜索」按钮

**验收**：识别结果可查看和修正。

---

### T4: 识别结果 → 搜索联动 `[x]`

- 确认后调用 `POST /api/v1/images/match` 或跳转搜索结果页
- 复用 `02-search-results` 组件展示候选

**验收**：铭牌识别后可看到配件推荐。

---

### T5: 异常场景 UI `[x]`

| 场景 | UI 处理 |
|------|---------|
| 图片模糊 | 提示重传 + 拍摄建议 |
| OCR 无文字 | 引导手动填写铭牌表单 |
| 仅识别到型号 | 展示设备信息 + 配件系统选择 |
| 无匹配 | 转人工查询按钮 |

**验收**（PRD §8.3 异常表）：各异常有对应 UI。

---

### T6: 拍摄规范提示 `[x]`

- 上传区域旁展示：光线充足、对焦清晰、完整铭牌入镜
- 示例图片（可选）

**验收**：降低用户上传模糊图概率。
